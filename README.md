# مدرسة ألحان تي اتشرومبي

بوابة إلكترونية لعرض نتائج الطلاب وإعلانات المدرسة، مع تجهيز البنية لإدارة الطلاب والمواد والفصول والدرجات والصلاحيات.

## التقنية
- React + TypeScript + Vite
- Supabase فقط للمصادقة وقاعدة البيانات وواجهات البيانات
- GitHub لإدارة الكود

## التشغيل محليًا
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env.local`.
4. أضف رابط مشروع Supabase والمفتاح العام (Publishable أو anon) إلى `.env.local`.
5. نفّذ `npm run dev`.

## إعداد Supabase
1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح SQL Editor وشغّل الملف `supabase/schema.sql` مرة واحدة.
3. شغّل بعده الملف `supabase/hardening.sql` لتفعيل قيود تطابق الفصل والطالب والمادة وصلاحيات إدخال الدرجات.
4. رابط مشروع Supabase مضبوط بالفعل في `.env.example`. انسخ الملف إلى `.env.local` وضع فيه المفتاح العام Publishable الذي حصلت عليه من إعدادات المشروع.
5. لا ترفع ملف `.env.local` إلى GitHub. أنشئ حساب المسؤول الأول من Supabase Auth، ثم أضف سجلًا مطابقًا لمعرّف الحساب في جدول `profiles` واجعل دوره `super_admin`.

## الأمان
- لا تضع مفتاح `service_role` أو أي مفتاح سري في الواجهة أو GitHub.
- سياسات RLS مفعّلة في مخطط قاعدة البيانات.
- البحث العام يستخدم دالة محدودة تعرض النتائج المنشورة فقط.
- لا تُدخل بيانات طلاب حقيقية قبل مراجعة إعدادات المشروع وسياسات الوصول.
